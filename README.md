# نظام الجدول المدرسي

موقع ثابت يعمل على GitHub Pages بلا خادم وبلا قاعدة بيانات، ومناسب للجوال واللوحي والحاسوب.

| الملف | الصفحة |
|---|---|
| `index.html` | الجدول الأسبوعي |
| `cover.html` | إشغال الغياب |

## العروض المتاحة

| العرض | ما الذي يعرضه |
|---|---|
| 📘 حسب الصف | جدول الصف الأسبوعي كاملًا + توزيع المواد + معلمات الصف |
| 👩‍🏫 حسب المعلمة | جدول المعلمة الأسبوعي + مجموع النصاب + الحصص الفارغة لكل يوم |
| 📆 حسب اليوم | كل الصفوف في جدول واحد ليوم واحد + تنبيه للحصص المشتركة |
| 🔁 الإشغال | المعلمات المتفرغات في كل حصة — تُحسب تلقائيًا من الجدول |

يوم اليوم يُظلَّل تلقائيًا، وزر **🖨️ طباعة** يطبع العرض الظاهر فقط.

## صفحة الإشغال

صفحة مستقلة لإدارة الغياب: اختاري اليوم، ثم المعلمة (أو المعلمات) الغائبة،
فتُبنى خطة إشغال كاملة ويُعرض جدول اليوم بعد التعديل.

**قيود تضمن خلوّ الخطة من التضارب:**

- البديلة متفرغة أصلًا في تلك الحصة حسب الجدول.
- البديلة ليست ضمن الغائبات.
- لا تُسنَد إلى البديلة أكثر من حصة واحدة في الحصة نفسها.

**ترتيب المفاضلة بين المتفرغات:**

1. من تُدرّس المادة نفسها لهذا الصف.
2. من تُدرّس المادة نفسها.
3. من تُدرّس الصف نفسه.
4. الأقل عددًا في حصص الإشغال ذلك اليوم (توزيع عادل).
5. الأقل نصابًا أسبوعيًا.

**الخيارات:**

- *أولوية التوزيع للحصص الأخيرة* (مفعّلة افتراضيًا): يبدأ التوزيع من آخر حصة
  في اليوم نحو أولها، فتنال الحصص الأخيرة أفضل المتفرغات المتاحات.
- *حد الإشغال لكل معلمة*: العدد المفضَّل الذي لا تتجاوزه المعلمة الواحدة،
  ويُتجاوز عند الضرورة القصوى فقط.

الخطة **أوّلية وقابلة للتعديل**: لكل حصة قائمة منسدلة لا تعرض إلا المعلمات
المتفرغات فعليًا، فأي تبديل يدوي يبقى بلا تضارب. وزر **📋 نسخ الخطة** ينسخ
ملخّصًا نصيًا جاهزًا للإرسال.

## تعديل الجدول

كل البيانات في ملف واحد: `data.js`.

### تغيير حصة

كل خلية نصٌّ بصيغة `"المادة|المعلمة"`، والخلية الفارغة `""`.
ترتيب الخلايا داخل كل حصة هو نفس ترتيب `CLASSES` تمامًا:

```js
const CLASSES = ['الأول','الثاني','الثالث','الرابع','الخامس',
                 'السادس','السابع','الثامن','التاسع أ','التاسع ب'];
```

فلتغيير الحصة الأولى من يوم الأحد للصف الثالث، عدّلي الخلية الثالثة من أول قائمة تحت `'الأحد'`.

### إضافة أوقات الحصص

املئي `PERIOD_TIMES` لتظهر الأوقات تحت اسم كل حصة:

```js
const PERIOD_TIMES = [
  { start: '08:00', end: '08:45' },
  { start: '08:45', end: '09:30' },
  ...
];
```

### إضافة مادة جديدة

تعمل المادة الجديدة مباشرة. ولإعطائها لونًا خاصًا أضيفيها إلى `SUBJECT_COLORS`.

## ملاحظات

- أسماء المعلمات وقوائم المواد تُستخرج تلقائيًا من الجدول، فلا حاجة لتحديثها يدويًا.
- إذا ظهرت معلمة في صفّين بالحصة نفسها ينبّه عرض «حسب اليوم» إلى ذلك، لأنه إمّا حصة مدمجة أو خطأ إدخال.
